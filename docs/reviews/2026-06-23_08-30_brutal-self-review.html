04Remaining Gaps

NodeShapeBox / NodeShapeRect duplicate

Two exported names for the same visual concept. Every renderer treats them identically. Can't remove pre-v1 (ADR 006 stability). Low priority — cosmetic, not functional.

No dedicated tests for escape fixes on style values

The 5 injection fixes are verified by existing tests passing, but no test explicitly asserts that escape.D2("malicious\ninput") is applied to style values specifically. Medium priority — should add targeted injection tests.

NOM-mode scroll renders entire tree before clipping

tui/render_nom.go:50-51 renders with height=0 then clips. Non-scroll path uses VisibleEntriesWithSnapshots. O(n) for large trees. Low priority — performance, not correctness.

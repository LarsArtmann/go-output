01Fixed on the Spot

Critical Bug

Progress bar panics on narrow terminals

tui/view.go:207-213

strings.Repeat panics when terminal width is 1-29, producing a negative bar width. Fixed with a width < 1 guard.

Critical Bug

handleStepUpdate matches wrong step

tui/model.go:233

|| m.steps[i].isActive() matched ANY active step, not the intended one. With concurrent steps, updates overwrote the wrong step. Fixed: match by message only.

Critical Bug

Total=0 instantly marks step completed

tui/model.go:238

Unsigned comparison Current >= Total is always true when Total=0. Fixed with msg.Total > 0 && guard.

Bug

Double "s" suffix in elapsed time display

tui/summary.go:68,72,74

Templates had {time}s but formatElapsedTime already returns unit-suffixed strings ("1.5s", "500ms"). Output was "1.5ss". Fixed: removed trailing s.

Injection

DOT node color attributes not escaped

graph/dot.go:196-214

writeNodeAttr wrote fillcolor/color without quoting or escaping. Edges were escaped but nodes were not. Fixed: quote and escape all node attributes.

Injection

D2 style values not escaped

d2/d2_write.go:12,21,37,60

Fill, Stroke, FontColor, TextTransform values were written raw. A newline in a color value could inject D2 directives. Fixed: escape.D2() applied.

Injection

Mermaid node ID not escaped in style directive

graph/mermaid.go:144

Style directive used raw node.ID.Get() while the node definition used escape.MermaidID(). Styling silently failed for IDs with special chars. Fixed.

Injection

02Noted (Not Fixed — Design Decisions)

RowEdge uses raw string instead of branded GraphNodeID

tabledata.go:174-178 — RowEdge.From/To are raw string while the rest of the graph type system uses branded IDs. AddRowEdges immediately re-wraps them. This is an internal-only type boundary that could be tightened.

NodeShapeBox and NodeShapeRect are semantic duplicates

graph.go:45,52 — Two exported names for the same visual concept. All renderers treat them identically. Removing one would be a breaking change (pre-v1 API stability per ADR 006).

LineStyle enum is incomplete

graph.go:67-89 — Has IsValid() but lacks ParseLineStyle, AllowedValues(). Inconsistent with other enums.

SetCancelFunc/SetDisplayMode write without synchronization

tui/reporter.go:77,84 — Doc says "Must be called before Start()" but no enforcement. displayMode is read under lock in lifecycle.go. Low risk if used as documented.

NOM-mode scroll renders entire tree before clipping

tui/render_nom.go:50-51 — When scrolling, renders with height=0 then clips. Non-scroll path uses VisibleEntriesWithSnapshots. O(n) render for large trees when scrolling.

02 What Is Stupid?

The strings.Replace marker injection hack

samber-do-auditlog's html.go renders HTML to a buffer, then does strings.Replace(buf.String(), "// DAGHTML_JS_INJECTION_POINT", daghtml.Script(), 1). This is a magic string in a templ file, replaced at runtime. It's fragile: if the marker is accidentally modified or removed, the graph JS silently disappears. This exists because templ v0.3.x doesn't evaluate expressions inside <script> text nodes — but it should be documented better.

Leaving the build broken across sessions

The samber-do-auditlog build was broken at the end of a previous session and stayed broken until this session. No partial work should ever be left in a non-compiling state — at minimum, the go.mod should have been updated before stopping.

03 What Could I Have Done Better?

  • Complete tasks in one pass. The samber-do-auditlog refactoring should have been finished — go.mod, templ generate, tests, commit — all in the same session. Instead it was left at ~50% (not 70% as claimed).
  • Cross-check selectors. When extracting shared JS that uses querySelector(".graph-zoom-in"), verify every consumer's HTML uses class= not id=. This is a 30-second check that would have caught the bug.
  • Lint immediately. Any new module should pass nix run .#lint before its first commit. The 7 lint violations should never have existed in a committed module.
  • Add golden tests as part of module creation. Not as a follow-up "quality improvement" task weeks later.

04 What Could I Still Improve?

daghtml Node.Color is a bare string

The Color field accepts any string — "var(--success)", "#ff0000", "red", or garbage. A Color type with constructors (CSSVar("success"), Hex("#ff0000")) would be more type-safe. Verdict: YAGNI for now — the current bare string is intentional simplicity for a zero-dep SDK. Revisit if the pattern causes bugs.

Versioning strategy unresolved

daghtml is zero-dep (like testhelpers) and independently publishable. But it hasn't been tagged yet. Both consumers use v0.0.0-… + replace for local dev. For releases, daghtml needs its own semver tag. Recommendation: tag as daghtml/v0.1.0 independently, matching the testhelpers pattern.

06 How Can We Be Less Stupid?

  • Run nix run .#lint on every new module before committing. No exceptions.
  • Never leave a build broken. If you stop mid-refactor, the go.mod must compile.
  • Always run templ generate after modifying .templ files.
  • Cross-check HTML selectors against JS querySelector calls. 30 seconds saves a silent bug.
  • Be honest about completion percentage. "Tests pass" means nothing if a test asserts nothing.

Strengths

Domain-aligned type names

TableData, TreeNode, GraphNode, DependencyTree, ActivitySnapshot, TimingCache, InlineRenderer — every name speaks the domain language. No technical jargon leaking into domain concepts.

Consistent verb vocabulary

Create/Add/Set for mutation, Render/Marshal/Write for output, Parse/Contains/IsValid for validation. No synonym drift (no fetch/retrieve/query mixing with get).

Honest function names

RenderTableData() renders table data. NewCSVWriter() creates a CSV writer. ParseFormat() parses a format. No lying names, no hidden side effects.

Get prefix is intentional, not accidental

TableData.GetHeaders() etc. exist to satisfy the TableDataProvider interface and test doubles. Documented in TODO_LIST.md #15 as resolved — "load-bearing, not duplication."

04Totally Fucked Up!

Resolved

Experimental JSON imports broke the whole workspace

marshal.go, serialization/*.go, daghtml/assets.go

An automated repair (likely go-auto-upgrade or a golangci-lint fix) rewrote standard encoding/json usage to encoding/json/v2 and encoding/json/jsontext. These packages are only available when the Go toolchain is built with the GOEXPERIMENT=jsonv2 build tag. Because flake.nix's test, test-race, and build apps do not set that experiment, every module that imported the root package or the serialization module failed with: 

imports encoding/json/v2: build constraints exclude all Go files
imports encoding/json/jsontext: build constraints exclude all Go files

This cascaded into two BuildFlow failures:

  • test-race — exit status 1 from go test.
  • hierarchical-errors:repair — exit status 75, presumably because it could not parse the broken import tree.
Fix Reverted all affected imports to the stable encoding/json API. The workspace is now green.

05What We Should Improve

!
Stop guessing what an auto-fix will change I should have inspected the diff produced by the auto-fix run before assuming it was only dependency bumps. A single git diff would have shown the import rewrites immediately.
!
Recognize GOEXPERIMENT errors faster "build constraints exclude all Go files" for a stdlib package is the classic signature of an experimental package. I should have checked go env GOEXPERIMENT and the package directory in the Go root sooner.
!
Run targeted tests before the full BuildFlow After the import change, I ran a quick go test in the root module, which succeeded because the root module has no tests that hit those imports. I should have tested serialization and daghtml immediately, which would have caught the problem earlier.
!
Protect the root module's portability The root module is advertised as independently go get-able with no experimental requirements. If we ever intentionally adopt encoding/json/v2, it must be gated behind a build tag or moved to a sub-module, not forced on every consumer.
!
Add a CI gate for forbidden imports A simple script checking for encoding/json/v2 or encoding/json/jsontext imports (unless a deliberate opt-in is set) would prevent this class of breakage.

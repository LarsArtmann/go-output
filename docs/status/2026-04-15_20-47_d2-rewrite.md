# D2 Output Format — Comprehensive Rewrite

**Date:** 2026-04-15 20:47 CEST
**Branch:** master
**Previous Status:** 2026-04-11 (4 days ago)

---

## Summary

Complete rewrite of D2 diagram output support. The previous implementation had **broken syntax rendering**, silently discarded edge styles, ignored table data rows, and lacked `GraphRenderer` interface compliance. The rewrite fixes all issues and brings D2 support to parity with DOT and Mermaid formatters.

---

## What Changed

### `d2.go` — Core types and rendering (complete rewrite)

**Syntax fixes:**
- Edge styles (stroke, width, animated, dashed) now rendered via D2 block syntax instead of being silently discarded
- Edge arrows now use `source-arrowhead.shape` / `target-arrowhead.shape` in block syntax instead of invalid inline syntax (`-diamond->`)
- Nodes with shapes/styles use D2 block syntax (`id: label { shape: circle }`)
- Added `escapeD2()` for proper string escaping (quotes, newlines, tabs)

**New features:**
- `D2Direction` type with constants (Down, Right, Left, Up)
- 6 new node shapes: Triangle, SQLTable, Image, Code, Text, Class
- `D2NodeStyle.Opacity` (float64) and `D2NodeStyle.Shadow` (bool)
- `D2Node.Icon`, `D2Node.Link`, `D2Node.Tooltip` fields
- `D2ArrowFilled` and `D2ArrowCircle` arrow types
- Diagram-level config: `SetDirection()`, `SetLayout()`, `SetTitle()`
- `D2NodeStyle.isSet()` extracted to reduce cyclomatic complexity

**Breaking changes:**
- `D2ArrowOval` → `D2ArrowCircle` (deprecated alias preserved)
- `D2ArrowPoint` → `D2ArrowArrow` (deprecated alias preserved)
- `D2FromTableData()` now creates per-row nodes + edges instead of single table shape
- Node/edge rendering output format changed to block syntax

### `d2_convert.go` — New file (~130 lines)

- `D2Diagram.SetNodes([]GraphNode)` — satisfies `GraphRenderer` interface
- `D2Diagram.SetEdges([]GraphEdge)` — satisfies `GraphRenderer` interface
- `D2FromTableData(*TableData)` — creates per-row nodes with labels and edges between consecutive rows
- `D2FromTree(*TreeNode)` — converts tree hierarchy to D2 nodes + edges recursively
- Conversion helpers: `graphNodeToD2()`, `graphEdgeToD2()`, `graphShapeToD2()`, `graphStyleToD2()`

## Architecture Decisions

1. **Two-file split**: `d2.go` (core types + rendering) and `d2_convert.go` (interface compliance + conversion). Separates concerns cleanly.
2. **Block syntax over inline**: D2 supports both, but block syntax is required for any non-trivial attributes. Produces valid, idiomatic D2.
3. **Branded IDs**: D2Node uses `D2NodeID`/`D2NodeLabel` branded types consistent with project patterns.
4. **Method chaining**: All `Add*`/`Set*` methods return `*D2Diagram` for fluent API.

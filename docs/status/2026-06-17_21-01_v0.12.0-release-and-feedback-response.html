During the version bump I ran sed 's/v0.11.0/v0.12.0/g' across all go.mod files, which accidentally bumped the external dependency github.com/clipperhouse/displaywidth from v0.11.0 to v0.12.0. e) WHAT WE SHOULD IMPROVE!

Release automation

Manual sed across 16 go.mod files is error-prone. A small release script (or flake app) that bumps versions, tags, and pushes would eliminate this class of mistake.

Type models

RankDir and SplineStyle are typed enums, but nodesep/ranksep are still strings. They could become typed numeric distance values with validation. Also consider whether DOT should support a GraphStyle-like global graph style object.

Well-established libraries

Width/ANSI handling in nom/ already delegates to charmbracelet/x/ansi. For future graph layout concerns, consider whether gonum/graph could power layout/edge routing helpers instead of hand-rolled DOT strings.

Documentation discoverability

The StreamingRenderer adapter pattern is documented in code but not prominent. A "Streaming output" section in AGENTS.md would help consumers like Issue 7.

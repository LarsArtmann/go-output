## Issues Found & Fixes Applied

### 1. Missing replace directives for testhelpers ❌ → ✅ FIXED

**delimited/go.mod** and **markup/go.mod** required `testhelpers` but lacked `replace` directives for it, violating the project's convention that every module must be buildable standalone.

**Fix:** Added `replace github.com/larsartmann/go-output/testhelpers => ../testhelpers` to both files.

### 2. CI workflow omitted testhelpers/graphtest ❌ → ✅ FIXED

`.github/workflows/ci.yml` did not build, test, or run `go mod tidy` on `testhelpers/graphtest`.

**Fix:** Added `testhelpers/graphtest` to all four module loops (build, test, coverage, tidy, govulncheck).

### 3. flake.nix checks misconfigured ❌ → ✅ FIXED

`checks.format` was nested inside `pre-commit.settings.hooks` instead of being a top-level `perSystem` output, causing `nix flake check` to fail.

**Fix:** Moved `checks.format` to the correct location in `flake.nix`.

## Recommendations

1. **Root god-package (long-term):** Root is ~5,200 LOC with 7+ concerns. Consider extracting renderers (markdown, tree) to sub-modules in a future major version. Not urgent — root is the intended public API surface.
2. **Keep `go.work` gitignored:** Current practice is correct. Do not commit it.
3. **Document test-only imports:** Add a note to `AGENTS.md` clarifying that root's `delimited`/`serialization` dependencies are test-only and do not affect consumers.

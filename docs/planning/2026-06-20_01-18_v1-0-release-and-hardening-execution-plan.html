Research findings that shaped this plan

  • Zero inline TODO/FIXME comments anywhere in the codebase — all work items come from docs, not code markers.
  • All 11 deprecated symbols have ZERO production callers (5 functions + 6 color aliases) — safe to delete outright.
  • Paused is a fully-decorated dead end: symbols, colors, shapes, sort priority all defined, but no EventActivityPaused constant, no handler, and SetPaused() has zero callers. The only way to reach it is direct field assignment in tests.
  • Bonus smell: ActivityStatusPending reuses Paused's symbol/color — Pending and Paused are visually indistinguishable. Fixing this is folded into the Paused removal.
  • TableData getters are load-bearing (back the TableDataProvider interface in table/table.go + test doubles) — NOT redundant duplication. Closes TODO #15.

01Decisions Resolved

Resolved during research so execution can proceed without blocking on ambiguity. Each is reversible pre-v1.0.

Decision

D1 — SetPaused / ActivityStatusPaused: REMOVE

nom/activity_status.go, nom/activity.go, nom/status_mappers.go

Option B chosen over wiring (Option A). Rationale: zero callers, no event path, YAGNI ("don't build for imagined future needs"), pre-v1 experimental API. Pending reusing Paused's color/symbol is a real ambiguity bug that removal also fixes. Reversible: if a real CI pause/resume use case emerges, re-add WITH a proper event path before v1.0 stabilization.

Veto window Owner can object before v1.0 tag — this is the single most opinionated call in the plan.
Closed

D2 — TableData fields vs getters (#15): KEEP BOTH

tabledata.go:79, table/table.go:44

GetHeaders()/GetRows() satisfy the TableDataProvider interface consumed by table/table.go and test doubles. They are load-bearing abstraction, not redundant accessors. Document the rationale; no code change.

Closed

D3 — otter/v2 for TimingCache: KEEP hand-rolled

nom/timing_cache.go

The cache is a capped map+slice, already concurrency-safe with lock-free reads (fixed last sprint), eviction handled. Adding a dependency for a solved, tiny, hot-tuned structure violates the root-light philosophy. Document rationale; no code change.

Verified

D6 — go.work gitignored (#22/#23): ALREADY DONE

.gitignore:19-20

go.work and go.work.sum are gitignored; go.work.example is tracked and current. No action beyond a docs note.

## Verification Protocol

After EACH commit:
1. `nix run .#build` — all modules compile
2. `nix run .#test` — all tests pass
3. `nix run .#lint` — zero lint issues

After structural phases (E, F, G):
4. `nix run .#test-race` — nom + tui race-free
5. `nix run .#govulncheck` — zero vulnerabilities

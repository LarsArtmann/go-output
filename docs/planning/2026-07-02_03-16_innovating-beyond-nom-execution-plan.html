00Pareto Breakdown

The 1% that delivers 51%

Critical Path Highlighting, Blockage View, Convergence Markers. These use the DAG data we already have — zero model changes, pure rendering. They answer the two questions users ask most: "what matters?" and "why is this blocked?"

The 4% that delivers 64%

Open Status Registry + Theme System. These unblock all non-Nix use cases (CI pipelines with skipped/cached/warning states) and make the library themeable (table stakes for adoption). They're foundational — Category Tints and Layered Mode depend on them.

The 20% that delivers 80%

Layered Display Mode (the flagship), Critical Path ETA, Category Tints, Compact DAG Summary. These are the features that make go-output visibly different from nom.

The 80% that delivers the last 20%

Smart Layer Filtering, Critical-Path Priority Sort, Interactive DAG TUI View. These improve UX at scale and add user agency. Worth doing, but not until the foundation is solid.

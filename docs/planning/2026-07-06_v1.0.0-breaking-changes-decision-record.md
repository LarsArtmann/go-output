## Detail: `GraphRendererState` → ??? (C5) — PENDING DECISION

**What it is:** An embedded struct providing shared `AddNode`/`AddEdge`/`nodes`/`edges` state to DOT/Mermaid/PlantUML renderers via composition. 48 references.

**Why rename:** "State" implies volatile runtime state. It's actually a shared data store / mixin for graph renderers.

## Detail: Renderer Interface (C9) — Keep, Note Smell

`Renderer.Render() (string, error)` — 6 implementations always return nil. Decision: **keep** (forward-compatible), document as code smell in `ROADMAP.md`.

**The smell:** Even stdout can error (broken pipe). Pure-string renderers that can't fail are forced to return nil. Future direction: evaluate whether renderers should do their own I/O (writing to `io.Writer`) instead of returning strings, so real errors propagate.

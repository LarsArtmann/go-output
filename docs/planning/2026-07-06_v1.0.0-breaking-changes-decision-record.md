## 1. Context

This project (`go-output`) is a multi-module Go library for CLI output formatting (16 formats across table/tree/graph shapes) plus NOM-style real-time progress visualization. It has NOT yet tagged v1.0.0. ADR 006 declares the API frozen, but since no v1 tag exists, this is the **last opportunity** for clean breaking changes without deprecation shims.

After v1.0.0, every breaking change requires a `// Deprecated:` marker maintained until v2.

This document records ALL decisions made during the 2026-07-05/06 session to prepare the v1.0.0 release.

## 4. v1.0.0 Breaking-Change Decisions

### Already Applied (in uncommitted work)

| Decision                                                       | Status                              |
| -------------------------------------------------------------- | ----------------------------------- |
| `SemanticColors.Info` → `.Fallback`                            | ✅ Applied (hard rename, ~15 files) |

### Approved — To Execute Before v1.0.0 Tag

#### B1-B9: Delete All Deprecated Shims (9 symbols)

Since v1.0.0 hasn't been tagged, delete instead of carrying deprecation markers:

| #   | Symbol                               | Action                                            | Reason                                                    |
| --- | ------------------------------------ | ------------------------------------------------- | --------------------------------------------------------- |
| B1  | `NOMStyleSubscriber` type            | Delete old name, rename struct to `NOMSubscriber` | "Style" adds nothing                                      |
| B2  | `NewNOMStyleSubscriber()`            | Delete, consumers use `NewNOMSubscriber()`        | Follows B1                                                |
| B3  | `GetDependencyTree()`                | Delete                                            | `DependencyTree()` is identical                           |
| B4  | `ErrActivityNotFound`                | Delete                                            | Never returned by any function                            |
| B5  | `TimingFormat` constant              | Delete                                            | `FormatDuration()` handles everything                     |
| B6  | `Activity.IsPhase()`                 | Delete                                            | `ActivitySnapshot.IsPhase()` is the concurrency-safe path |
| B7  | `EdgeStyle.ArrowHead` + `.ArrowTail` | Delete fields                                     | Never read by any renderer                                |
| B8  | `NodeShapeRect`                      | Delete fully — NO parse alias for `"rect"`        | Go all-in on `NodeShapeBox`                               |
| B9  | `StreamingRendererFromRenderer`      | Delete                                            | `RendererAsWriter` replaces it                            |

**Important note on B8:** `ParseNodeShape("rect")` will return an error after this change. Any consumer config files using `"rect"` must migrate to `"box"`. This is intentional — the shapes are identical and maintaining a ghost alias adds complexity for no value.

**Blast radius:** ~647 references. This is the largest rename in the project.

| Old                          | New                      |
| ---------------------------- | ------------------------ |

| `TableDataStore`             | `TableStore`             |
| `TableDataRenderer`          | `TableRenderer`          |
| `AnyDataRenderer`            | `UnknownRenderer`        |
| `RenderTableData()`          | `RenderTable()`          |
| `RenderAnyData()`            | `RenderUnknown()`        |
| `NewMarkdownTableFromData()` | `NewMarkdownTable()`     |
| `DOTFromTableData()`         | `NewDOTFromTable()`      |
| `MermaidFromTableData()`     | `NewMermaidFromTable()`  |
| `D2FromTableData()`          | `NewD2FromTable()`       |

| `D2FromTree()`               | `NewD2FromTree()`        |

**Decision:** Approved. "Do it once correctly."

**Decision:** Approved.

#### C4: `GraphStyle` → `NodeStyle`

59 references. The current name implies it styles the entire graph; it only styles nodes.

**Decision:** Approved. `NodeStyle` paired with existing `EdgeStyle`.

#### C5: `GraphRendererState` → (PENDING — needs final name)

The user rejected `GraphStore` ("sounds like disk persistence"). This is an embedded struct providing shared `AddNode`/`AddEdge`/`nodes`/`edges` state to DOT/Mermaid/PlantUML renderers.

**Candidate names to decide:**

- `GraphCore` — "the core shared state for graph renderers"
- `GraphBase` — "base implementation to embed" (Go's `Base` convention)
- `GraphModel` — "the graph model (nodes + edges)"
- `GraphElements` — "a collection of graph elements"
- `GraphNodeEdges` — literal but descriptive
- `GraphCollection` — "a collection of nodes and edges"

**Decision:** PENDING — user to choose from the above (or propose new name).

#### C6: `TreeOutputRenderer` → `TreeRenderer`

8 references. Inconsistent "Output" suffix removed.

**Decision:** Approved.

#### C9: Renderer Interface Error Return

`Renderer.Render() (string, error)` — 6 implementations always return nil error. Decision: keep as-is (forward-compatible), but document as a code smell in `ROADMAP.md`.

The smell: even stdout can error (broken pipe). Pure-string renderers that can't fail are forced to return nil. Future improvement: evaluate whether renderers should do their own I/O (writing to `io.Writer` and returning real errors) instead of returning strings.

**Decision:** Keep interface. Note in `ROADMAP.md`.
